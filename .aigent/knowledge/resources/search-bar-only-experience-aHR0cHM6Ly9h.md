## Overview
**Home page - **Visitor can use the custom search bar component that gives the nearest gym.

**Training page and sub pages - **Visitor can search for a location using the search bar, and once a gym is selected from the list of results, it will redirect to the Find Gym page.

## Home Page
**Search Behavior: **

- Prefill the search bar with the visitor’s currently detected location on initial load. The **“Locations Near You” **component also displays the nearest gym.
- Searching for a location also updates the **"Locations Near You"** component with the nearest gym from the search result.
- Using **"Use my precise location"** also retrieves the visitor's current location and the nearest gym.
**Where the buttons redirect**

- **TRY US FREE - **Try us free lead form page for that specific gym e.g [https://{env}.anytimefitness.com/try-us-free?location_id=5688](https://www.anytimefitness.com/try-us-free?location_id=5688)
- **JOIN NOW - **The gym **“Join Now”** page where available plans can be viewed and selected. e.g [https://join.anytimefitness.com/5688/plans](https://join.anytimefitness.com/5688/plans)
- **VIEW ALL NEARBY LOCATIONS - **[Find Gym ](https://www.anytimefitness.com/find-gym)page

## Training Page
**Search Behavior:  **Searching on the Training page and sub pages will display a list of gym results. Upon clicking a gym result, the visitor is redirected to the [Find Gym ](https://www.anytimefitness.com/find-gym)page.
